To find out which folder the file landed in, use getwd(); sheet names are listed by readxl::excel_sheets("potraviny.xlsx").

Long vs. wide format

In exercise 5a each product was in its own vector (wide format). The Excel file is in the long (tidy) format: one row = one rating, and the column produkt (product) says which sample it belongs to. This is the format that formulas such as kvalita ~ produkt expect.

How to read the output of pairwise.wilcox.test

    A      B      C

P value adjustment method: bonferroni

The (illustrative) table contains adjusted p-values for every pair. Here A differs from B and D, C from B and D; the pairs A–C and B–D do not differ. The result is usually written with letters: samples sharing a letter do not differ significantly (Aa, Ca, Bb, Db).

exact = FALSEWith tied values (almost always in sensory data – scales have few steps) R cannot compute an exact p-value and prints a warning. exact = FALSE switches to the normal approximation and removes the warning.
