EXERCISE 23

Wald's sequential analysis

A discrimination test evaluated after every answer: once the result is clear, the test stops early.

Script (SK): cvicenie23.RScript (EN): exercise23.R

What you will learn

  • to explain the difference between a test with a fixed number of assessors and a sequential test,
  • to compute the boundaries of a sequential test from p₀, p₁, α and β,
  • to evaluate the course of a test and know the risks of the sequential approach.

The idea

In a classical discrimination test the number of assessors is fixed in advance (exercise 14) and the data are evaluated only at the end. Wald's sequential probability ratio test (SPRT) decides after every answer: if there are already enough correct answers, the difference is established; if there are few enough, the test ends without a difference; otherwise the next assessor continues. It suits expensive samples or situations where assessors arrive one by one.

ParameterMeaningIn the script
p₀proportion of correct answers when guessing (H₀)1/3 (triangle)
p₁proportion we already consider a difference (H₁)0.5
αrisk of declaring a difference that does not exist0.05
βrisk of missing an existing difference0.20

Boundaries

D = ln(p₁/p₀) + ln((1 − p₀)/(1 − p₁)),  s = ln((1 − p₀)/(1 − p₁)) / D
upper: an = ln((1 − β)/α) / D + s·n  lower: bn = −ln((1 − α)/β) / D + s·n number correct ≥ an → difference; ≤ bn → no difference; otherwise continue

For the triangle test with the values from the script: s = 0.415; an = 4.00 + 0.415 n; bn = −2.25 + 0.415 n. At n = 20 at least 13 correct answers are needed for a difference (a = 12.3) and at most 6 for “no difference” (b = 6.05).

How many assessors does it save?

A simulation of 5,000 tests (part 3 of the script) compared with a classical triangle test at the same risks:

TruthMean number of assessorsConclusion “difference”
a difference exists (p = 0.5)36.783 % (power)
assessors are guessing (p = 1/3)26.74 % (type I error)
classical test with fixed n58power 80 %, α = 0.05

On average, roughly a third to a half fewer assessors are needed. But it is an average: half of the tests with a real difference end within 30 assessors, 10 % need more than 69 and 1 % more than 120.

Two warningsA sequential test has no end known in advance – always set a maximum number of assessors and a rule for what happens then. And sequential boundaries are not the same as “looking at the p-value after every assessor”: repeated testing with the classical binomial test would inflate the type I error considerably.

Task solutions

Click to expand a solution. Try the task on your own first – results were verified in R 4.5. The code continues from the variables in the script.

Task 1 – boundaries for the duo-trio test 
p0 <- 1 / 2; p1 <- 0.7; alpha <- 0.05; beta <- 0.10
D <- log(p1 / p0) + log((1 - p0) / (1 - p1))
slope <- log((1 - p0) / (1 - p1)) / D
c(slope = slope, upper_0 = log((1 - beta) / alpha) / D, lower_0 = -log((1 - alpha) / beta) / D)

s = 0.603; an = 3.41 + 0.603 n; bn = −2.66 + 0.603 n. The conclusion “difference” can come after 9 assessors at the earliest (all 9 correct: 9 ≥ 8.84), the conclusion “no difference” after 5 (no correct answer: 0 ≤ 0.36).

Task 2 – the sequence 0 1 0 0 1 0 0 0 1 0 0 0 
answers <- c(0, 1, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)
n <- seq_along(answers)
data.frame(n, correct = cumsum(answers), lower = round(lower(n), 2), upper = round(upper(n), 2))

After 12 assessors there are 3 correct answers; the lower boundary is 2.73 and the upper 8.98 – the test is not decided yet. If the 13th assessor also misses (3 ≤ 3.15), the test ends with “no difference”.

Task 3 – a smaller difference p₁ = 0.45

The boundaries move apart: s = 0.391; an = 5.63 + 0.391 n; bn = −3.16 + 0.391 n. The mean number of assessors rises to about 71 (if the difference exists) and 52 (if not); a classical test would need 111. The smaller the difference we want to detect, the longer the test takes – sequential or classical.
