EXERCISE 16

Mixed models

The assessor as a random effect: why and how to replace two-way ANOVA with an lmer model.

Script (SK): cvicenie16.RScript (EN): exercise16.R🎓 Slides

What you will learn

  • to tell fixed and random effects apart,
  • why the assessor is a random effect in sensory data and what that changes in the product test,
  • to build and read an lmer() mixed model and compare products with emmeans.

We do not want to conclude “product A is better than B” only for our 29 assessors, but for any similarly trained panel. The product test must therefore take into account how much assessors disagree about the products.

What changes in the product test

The model in R

library(lmerTest)
m <- lmer(Bitterness ~ Product + Session + (1 | Panelist) + (1 | Panelist:Product),
          data = sensochoc)
anova(m)     # F-test of fixed effects, Satterthwaite degrees of freedom
ranova(m)    # are the random effects needed? (likelihood ratio test)
VarCorr(m)   # variances of the random effects
Model partSensory meaning
Producttrue differences between samples – what we want to find
(1 | Panelist)each assessor uses a different part of the scale (shift up/down)
(1 | Panelist:Product)assessors disagree on the product order – panel disagreement
residualvariation between replicates – repeatability

Post-hoc: emmeans

TukeyHSD() does not work for a mixed model. The replacement is emmeans(m, pairwise ~ Product): it computes the estimated product means with confidence intervals and pairwise differences with the Tukey correction.

Unbalanced dataThe biggest advantage of lmer shows when ratings are missing (an assessor skipped a session). Classical ANOVA with a hand-chosen error term is then no longer exact; the mixed model copes with it.
The “boundary (singular) fit” warningIt means that some random effect has an estimated variance of 0 – the data do not need it. Exactly this happens for CocoaA (task 1): the interaction has p = 0.99, its variance is 0 and lmer merges it with the residual. The model is still usable, but consider simplifying it (ranova() shows which effect to drop).

Task solutions

Click to expand a solution. Try the task on your own first – results were verified in R 4.4. The code continues from the variables in the script.

Task 1 – CocoaA and the singular fit 
m1 <- lmer(CocoaA ~ Product + Session + (1 | Panelist) + (1 | Panelist:Product), data = sensochoc)
VarCorr(m1)
anova(m1)
summary(aov(CocoaA ~ Product * Panelist, data = sensochoc))

The assessor × product interaction is not significant (p = 0.99): its mean square (2.30) is even smaller than the residual one (3.29). Its variance estimate is therefore 0 → singular fit. The model effectively merges it with the residual: product F = 14.6 (fixed model 12.6). The conclusion is the same, products differ significantly.

Task 2 – the random effect Panelist:Session 
m2 <- lmer(Bitterness ~ Product + Session + (1 | Panelist) + (1 | Panelist:Product), data = sensochoc)
m3 <- update(m2, . ~ . + (1 | Panelist:Session))
anova(m2, m3, refit = FALSE)

χ² = 2.18; df = 1; p = 0.14, AIC almost equal (1481.3 vs. 1481.1), BIC worse. The assessor × session effect does not improve the model – the simpler model is enough. (refit = FALSE compares the REML fits, which is correct when the fixed effects are the same.)
