Data structures in R

Everything in R is a named object. We assign with the operator <- or =. By shape we distinguish four basic structures:

Matrix: transpose and inverse

t(m) swaps rows and columns. solve(m) returns the inverse matrix m−1, for which m · m−1 = I (the identity matrix). An inverse exists only for a square matrix with a non-zero determinant – in statistics you meet it e.g. in regression and PCA.

Loading data from the web

results <- read.table("http://…/export.txt", sep = ",")   # loads a table
str(results)     # column types – always check after loading
head(results)    # first 6 rows

source() executes code (defines variables, functions), read.table() only loads data. Only open files from the web from trusted sources – source() runs whatever is in the file.

Task 1 – molar masses 
source("http://senzorika.com/sait/datasety/mol.txt")   # defines C, H, K, O ...
sorbate <- 6 * C + 7 * H + K + 2 * O   # potassium sorbate C6H7KO2
citric <- 6 * C + 8 * H + 7 * O        # citric acid C6H8O7
c(sorbate, citric)
c(0.25 * sorbate, 0.1 * citric)        # grams per litre of brine

Potassium sorbate 150.22 g/mol, citric acid 192.12 g/mol. For 1 litre of brine: 0.25 mol of sorbate = 37.6 g and 0.1 mol of citric acid = 19.2 g.

Task 2 – generating a 9-point test 
set.seed(1)
melons <- expand.grid(assessor = paste0("H", 1:4), product = c("A", "B", "C"))
melons$odour <- sample(1:9, nrow(melons), replace = TRUE)
melons$taste <- sample(1:9, nrow(melons), replace = TRUE)
melons$texture <- sample(1:9, nrow(melons), replace = TRUE)
write.table(melons, "melons.txt", sep = ",", row.names = FALSE)

expand.grid() creates all assessor × product combinations (12 rows); each attribute is a random integer 1 – 9. The file is saved to the working directory (getwd()).

Task 3 – number of wafers and over-production 
chocolate <- read.table("http://senzorika.com/sait/datasety/cokolada.txt", sep = ",", header = TRUE)
area <- 2 * pi * 3.5^2 + pi * 7 * 1.5          # two bases + cylinder side (cm2)
per_piece <- area / 100 * 0.02                  # litres of chocolate per piece
chocolate$produced_pieces <- round(chocolate$spotrebacokolady / per_piece)
barplot(chocolate$produced_pieces, names.arg = chocolate$mesiace, las = 2)
abline(h = mean(chocolate$produced_pieces), col = "red")
chocolate$mesiace[chocolate$produced_pieces > mean(chocolate$produced_pieces)]

The wafer surface is 110 cm², so one piece needs 0.022 l of chocolate. Monthly production ranges from 57,523 (May) to 84,716 (November) pieces. Bonus: February, August, October, November and December are above average.
