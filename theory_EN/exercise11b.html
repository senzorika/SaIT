EXERCISE 11b

Text mining and sentiment analysis

From free-text reviews to word frequencies, a word cloud and emotions from the NRC lexicon.

Script (SK): cvicenie11b.RScript (EN): exercise11b.R🎓 Slides

What you will learn

  • to prepare free text (reviews, comments) for quantitative analysis,
  • to build a term-document matrix, a frequency chart and a word cloud,
  • to evaluate emotions and sentiment with the NRC lexicon.

From text to numbers

Open questions (“What did you like about the product?”) and online reviews are a rich source of information that a scale cannot capture. Text mining turns them into a table we can compute with.

The script skips cleaningThe script builds the matrix straight from the corpus, so conjunctions and punctuation will be among the most frequent “words”. Before TermDocumentMatrix add e.g.: 
TextDoc <- tm_map(TextDoc, content_transformer(tolower))
TextDoc <- tm_map(TextDoc, removePunctuation)
TextDoc <- tm_map(TextDoc, removeNumbers)
TextDoc <- tm_map(TextDoc, removeWords, stopwords("english"))

Row sums (rowSums) give the frequency of each word in the whole text – from them come the bar chart of top words and the word cloud, where font size corresponds to frequency.

Sentiment analysis – the NRC lexicon

The function get_nrc_sentiment() (syuzhet package) looks up every word in the NRC dictionary, where each word is assigned emotions according to Plutchik’s model, and counts them in every line of text. The result is 8 emotions and 2 polarities:

Language of the textNRC is an English lexicon by default. For texts in other languages try e.g. get_nrc_sentiment(text, language = "slovak") (if your syuzhet version supports it) – it is a machine translation of the dictionary without inflection, so it only catches the base forms of words. It is more reliable to analyse English reviews or translate the text.
LimitationsThe lexicon method does not see context: “not sweet at all” is counted as sweet, and irony is not recognised. Treat the results as indicative and verify them by reading a sample of the texts.
