R and RStudio – the engine and the dashboard

R is a free language and environment for statistical computing and graphics. On its own, R has only a simple console. RStudio (now made by Posit) is an integrated development environment (IDE) that runs R in the background and adds a script editor, a list of variables, and windows for plots and help. That is why we always install R first, then RStudio.

Packages – extensions of R

Base R contains the common tests (t-test, χ², ANOVA). Specialised methods – e.g. sensory discrimination tests (sensR), preference maps (SensoMineR) or financial charts (quantmod) – come in packages. A package is installed once on the computer but loaded every time R starts.

install.packages("sensR")   # once – downloads and installs
library(sensR)              # every time R starts
?binom.test                 # help for a function
Watch out for archived packagesSome packages (e.g. PMCMR, turfR) were removed from CRAN. The scripts in this course therefore use replacements (PMCMRplus) or installation from the CRAN archive. The error there is no package called … almost always means the package is not installed.

Groupware and collaborative work

A sensory project (sample preparation, evaluation, analysis, report) is teamwork. The tools differ by what we share:
