Grafy po vrstvách

V základnej grafike R najprv nakreslíme „plátno“ funkciou plot() a potom doň pridávame vrstvy – nič sa neprekresľuje:

plot(lin1, type = "l", main = "Plnenie", xlab = "s", ylab = "ml")  # plátno + 1. linka
lines(lin2, col = "lightblue")        # 2. linka
abline(h = mean(lin1), col = "red")   # vodorovná čiara priemeru
grid(nx = 6, ny = NA, col = "gray")   # zvislá mriežka
Finančné grafySviečkový graf (candleChart z balíka quantmod) zobrazuje pre každý deň otváraciu, zatváraciu, najvyššiu a najnižšiu cenu. Indikátory ako MACD, RSI či Bollingerove pásma sú kĺzavé štatistiky nad týmito dátami – rovnaký princíp, aký používa aj regulačný diagram pri kontrole kvality výroby.
Častá chybabarplot(a, b) nenakreslí dve série – druhý argument je šírka stĺpcov. Dve série kreslíme ako maticu: barplot(rbind(a, b), beside = TRUE).
