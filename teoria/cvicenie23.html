CVIČENIE 23

Waldova sekvenčná analýza

Rozlišovací test vyhodnocovaný po každej odpovedi: keď je výsledok jasný, test sa skončí skôr.

Skript (SK): cvicenie23.RScript (EN): exercise23.R

Čo sa naučíte

  • vysvetliť rozdiel medzi testom s pevným počtom hodnotiteľov a sekvenčným testom,
  • vypočítať hranice sekvenčného testu z p₀, p₁, α a β,
  • vyhodnotiť priebeh testu a poznať riziká sekvenčného prístupu.

Myšlienka

V klasickom rozlišovacom teste sa počet hodnotiteľov určí vopred (cvičenie 14) a vyhodnocuje sa až na konci. Waldov sekvenčný test pomerom vierohodností (SPRT) rozhoduje po každej odpovedi: ak je správnych odpovedí už dosť veľa, rozdiel je preukázaný; ak je ich dosť málo, test sa končí bez rozdielu; inak pokračuje ďalší hodnotiteľ. Hodí sa pri drahých vzorkách alebo keď hodnotitelia prichádzajú postupne.

ParameterVýznamV skripte
p₀podiel správnych odpovedí pri hádaní (H₀)1/3 (triangel)
p₁podiel, ktorý už považujeme za rozdiel (H₁)0,5
αriziko vyhlásiť rozdiel, ktorý neexistuje0,05
βriziko neodhaliť existujúci rozdiel0,20

Hranice

D = ln(p₁/p₀) + ln((1 − p₀)/(1 − p₁)),  s = ln((1 − p₀)/(1 − p₁)) / D
horná: an = ln((1 − β)/α) / D + s·n  dolná: bn = −ln((1 − α)/β) / D + s·n počet správnych ≥ an → rozdiel; ≤ bn → bez rozdielu; inak pokračovať

Pre triangel s hodnotami zo skriptu: s = 0,415; an = 4,00 + 0,415 n; bn = −2,25 + 0,415 n. Pri n = 20 treba na rozdiel aspoň 13 správnych (a = 12,3), na záver „bez rozdielu“ najviac 6 (b = 6,05).

Koľko hodnotiteľov ušetrí?

Simulácia 5 000 testov (časť 3 skriptu) v porovnaní s klasickým triangelom pri rovnakých rizikách:

SkutočnosťPriemerný počet hodnotiteľovZáver „rozdiel“
rozdiel existuje (p = 0,5)36,783 % (sila testu)
hodnotitelia hádajú (p = 1/3)26,74 % (chyba I. druhu)
klasický test s pevným n58sila 80 %, α = 0,05

V priemere teda stačí približne o tretinu až polovicu hodnotiteľov menej. Je to však priemer: polovica testov pri existujúcom rozdiele sa skončí do 30 hodnotiteľov, 10 % ich potrebuje viac ako 69 a 1 % viac ako 120.

Dve upozorneniaSekvenčný test nemá vopred známy koniec – vždy si stanovte maximálny počet hodnotiteľov a pravidlo, čo potom. A sekvenčné hranice nie sú to isté ako „pozrieť sa na p-hodnotu po každom hodnotiteľovi“: opakované testovanie klasickým binomickým testom by chybu I. druhu výrazne zvýšilo.

Riešenia úloh

Kliknutím rozbalíte riešenie. Skúste úlohu najprv vyriešiť sami – výsledky sú overené v R 4.5. Kód nadväzuje na premenné zo skriptu.

Úloha 1 – hranice pre duo-trio 
p0 <- 1 / 2; p1 <- 0.7; alfa <- 0.05; beta <- 0.10
D <- log(p1 / p0) + log((1 - p0) / (1 - p1))
sklon <- log((1 - p0) / (1 - p1)) / D
c(sklon = sklon, horna_0 = log((1 - beta) / alfa) / D, dolna_0 = -log((1 - alfa) / beta) / D)

s = 0,603; an = 3,41 + 0,603 n; bn = −2,66 + 0,603 n. Záver „rozdiel“ môže padnúť najskôr po 9 hodnotiteľoch (všetkých 9 správne: 9 ≥ 8,84), záver „bez rozdielu“ najskôr po 5 (žiadna správna odpoveď: 0 ≤ 0,36).

Úloha 2 – postupnosť 0 1 0 0 1 0 0 0 1 0 0 0 
odpovede <- c(0, 1, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)
n <- seq_along(odpovede)
data.frame(n, spravne = cumsum(odpovede), dolna = round(dolna(n), 2), horna = round(horna(n), 2))

Po 12 hodnotiteľoch sú 3 správne odpovede; dolná hranica je 2,73, horná 8,98 – test ešte nie je rozhodnutý. Ak sa pomýli aj 13. hodnotiteľ (3 ≤ 3,15), test sa skončí záverom „bez rozdielu“.

Úloha 3 – menší rozdiel p₁ = 0,45

Hranice sa od seba vzdialia: s = 0,391; an = 5,63 + 0,391 n; bn = −3,16 + 0,391 n. Priemerný počet hodnotiteľov stúpne na približne 71 (ak rozdiel existuje) a 52 (ak nie); klasický test by ich potreboval 111. Čím menší rozdiel chceme odhaliť, tým dlhšie test trvá – sekvenčný aj klasický.
