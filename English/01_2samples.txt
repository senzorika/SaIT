# ============================================================================
# THEORETICAL BACKGROUND
# ============================================================================
# Types of Two-Sample Discrimination Tests:
# 
# 1. Paired Comparison Test (Duo-Test)
#    - Probability of guessing: p = 0.5 (50%)
#    - Panelists compare two samples and indicate which has more of a specific attribute
#
# 2. Directional Difference Test
#    - Probability of guessing: p = 0.5 (50%)
#    - Panelists indicate which sample is stronger/more intense
#
# 3. Duo-Trio Test
#    - Three samples: one reference, two unknowns (one matches reference)
#    - Probability: p = 0.5 (50%)
#
# Statistical Methods:
# A. For Discrete Data: Binomial Test, McNemar Test, Chi-square Test
# B. For Continuous Data:
#    - Parametric: Paired t-test, Independent t-test
#    - Non-parametric: Wilcoxon Signed-Rank, Mann-Whitney U
# ============================================================================

# Example 1: Paired Comparison Test
# Question: Which yogurt is creamier?
# 80 panelists participated, 52 chose sample A

binom.test(52, 80, p=0.5)
# Interpretation: If p-value < 0.05, there is significant difference

# Calculate minimum number of correct responses needed
# For significance at α = 0.05
# Rule of thumb: For n=80, need at least 50 correct responses

# Check different values
for(i in 45:55) {
  result = binom.test(i, 80, p=0.5)
  cat("n =", i, ", p-value =", round(result$p.value, 4), 
      ifelse(result$p.value < 0.05, " *SIGNIFICANT*", ""), "\n")
}

n1 = length(brand_X_crispiness)

pooled_sd = sqrt(((n1-1)*var(brand_X_crispiness) +

    ifelse(abs(cohens_d) > 0.5, "Medium (0.5 < d < 0.8)",

    "represents a",

    "The packaging change SIGNIFICANTLY affected purchase intent.",

# d) Calculate proportions who changed

changed = positive_change + negative_change

  n = pwr.p.test(h=h, sig.level=0.05, power=0.80)$n
  cat("To detect", round(prop*100, 0), "% (vs 50%):", 
      ceiling(n), "panelists needed\n")
}

cat("
1. PROBABILITY VALUES FOR DISCRIMINATION TESTS:
   - Paired comparison / Duo-trio: p = 0.5 (50%)
   - Triangle / Tetrad: p = 1/3 (33.3%)
   
2. ALWAYS CHECK NORMALITY:
   - Use Shapiro-Wilk test (shapiro.test)
   - Visual inspection: Q-Q plots, histograms
   - If p > 0.05, data are normally distributed
   
3. PAIRED VS. INDEPENDENT:
   - Paired: Same panelists evaluate both samples
   - Independent: Different panelists for each sample
   
4. EFFECT SIZE INTERPRETATION (Cohen's d):
   - Small: d = 0.2
   - Medium: d = 0.5
   - Large: d = 0.8
   
5. STATISTICAL VS. PRACTICAL SIGNIFICANCE:
   - p < 0.05 = Statistical significance
   - Effect size = Practical significance
   - Both are important!
   
6. ALPHA LEVELS:
   - α = 0.05 (standard)
   - α = 0.10 (exploratory studies)
   - α = 0.01 (confirmatory studies)
   
7. POWER ANALYSIS:
   - Conduct BEFORE the study
   - Typical power = 0.80 (80%)
   - Ensures adequate sample size
